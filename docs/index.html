PayBack License (PBL)

The license used by every Ran# project. Free for personal, academic, and non-commercial use — commercial use requires a revenue-share agreement. This page tracks every published version of the license text.

Version 2.0current Released 2026-05-12

Adds a full governance framework on top of the v1.0 core: ownership and revenue-share tracking via a CONTRIBUTORS file, a GPG-signed voting process for project decisions, patent handling, fork requirements, succession, indemnification, and export-compliance terms.
